# Source inspection — 13 November 2026

Read from implementation, before building World. These are bounded inspections of the named files, not a claim to have audited every repository or reproduced their results. All repositories belong to `anttiluode` on GitHub. World uses newly written WebGL2 code and attributed algorithm adaptations, not a bundle of their renderers.

| Repository / inspected source | What the code actually does | Reuse decision |
|---|---|---|
| Moon: `build_network.py`, `exp.py` | Builds a sparse eight-layer arithmetic network from optical-depth quadrature, exponential attenuation, HG phase functions, escape probabilities and approximate multiple scattering. Its NumPy interpreter integrates the source along view rays. | Stage 3 reference for material-dependent transport and external-reference testing. Do not transplant its fitted constants into a different medium and claim its error bound. |
| CrystalMoon: `core.js` | Evolves a 3D Swift–Hohenberg field with cubic saturation, prescribed growth islands, density-dependent mobility, camera forcing and an inversion portal mapping. | Later: field growth, stability bounds, and lens topology. Not in stage 1. |
| CrystalMoonV2: `core.js` | Coarse and fine fields alter each other's growth; material blocks light, traced light feeds growth, and mirrored cells exchange state near a membrane. | Later: actual feedback, not its island masks or decorative appearance. |
| CrystalMoonV3: `core.js` | Extends V2 with wavelength-dependent ray bending; RGB photon deposition supplies brightness and blue-minus-red growth signals. | Later: dispersion only after a material/transport reference test. |
| Kerrostuma: `core.js` | Quenches a Swift–Hohenberg crust on a torus using metric derivatives and shear. Crust frustration feeds carriers; their deposited trail consolidates into gel whose conductivity changes excitation propagation. It already has real coupling, although it is not the full proposed loop. | Persistent material, physical state readouts, and history controls. No torus renderer or carrier population in stage 1. |
| Entrain: `core.py`, `grow.py` | Exponentially integrates complex Stuart–Landau states. Task errors accumulate in a gate; spectral residuals determine where new resonators are added; a class-separation score prunes nodes. | Adapt the damped nonlinear oscillator and exact rotation into a spatial GPU field. Growth of ears and classification are not ported. |
| Korva: `organ.py` | 52 binary delay rings, laps 13–64, compare eight bands, accumulate leaky mismatch, gate writes and select three low-surprise echoes. The separate transformer is not inside this file. | Adapt that organ, running at 8 Hz on CPU; use echo and mismatch to force the GPU. Do not call this a trained transformer. |
| MusicVisualizer1: `renderer.js`, `audio.js` | Audio bands feed six analytic visual modes; raymarched crystals and many curves are generated directly as functions of time/audio. Includes browser audio and adaptive rendering machinery. | Input/interaction lessons only. Its picture-generating formulas are deliberately not used as matter. |
| phi-world-theory: `SpaceScreensaver.py`; earlier inspection of `1dspacescreensavervectorbecomesbestuniverse.py` | The actual screensaver holds many tensor-core objects, moves them with pairwise forces and accumulates a density grid; it is not literally one scalar/vector oscillator. The projection experiment reduces a 1000-component state to 12 supplied mode coefficients before synthesizing a field. | Seeded multiscale structure only. No holography, quantum or discovered-law claim. |
| ComputingBeachClaude: `beach.js` | A leapfrog wave tank on a stadium graph; sand depth sets face conductance. Averaged wave-gradient stress changes sand, and changed sand refreshes wave propagation weights. | The central causal loop: forces alter matter and matter alters forces. World uses a new conservative transport rule rather than this tank's scour/clipping implementation. |
| Emergence: `emergence/world.py`, `genome.py`, `translator.py` | Seeded frozen transformer expresses token genomes as phenotype parameters. Cells sense neighbors, eat, share/steal energy, divide, die and mutate; lineage state feeds expression. Weights do not train. | Later: resource-limited growth and inherited traits. No claim that a simple spread rule would reproduce this transformer or evolution. |

Stage 1 therefore reuses **relationships**, with two explicit algorithm adaptations (Entrain integration, Korva organ). It does not import the other repositories' visual assets or claim their measured results.
